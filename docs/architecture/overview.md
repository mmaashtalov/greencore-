# Архитектура GreenCore

GreenCore строится как платформенное ядро, а не как одноразовое приложение для теплицы.

## Базовые сущности

- Asset — физический объект: теплица, склад, котельная и т. д.
- Device — реальное или виртуальное устройство.
- Telemetry — измерение параметра с единицей, временем и качеством.
- Command — унифицированная команда устройству.
- Rule — условие и действие.
- Digital Twin — модель состояния, поведения, рисков и экономики объекта.

## Слои

1. Domain model — стабильные контракты.
2. Simulation core — детерминированная модель поведения.
3. Application layer — сценарии, события, сравнение и API.
4. UI — публичная демонстрация и мобильная SCADA.
5. Integrations — MQTT, Modbus, OPC UA и другие протоколы.

## Принцип честного сравнения

Ручной и автоматический сценарии получают одинаковые:

- погоду;
- культуру;
- начальные условия;
- тарифы;
- длительность эксперимента.

Отличается только стратегия управления.

## Текущая граница MVP

В MVP нет реальных датчиков и оборудования. Виртуальные устройства реализуются теми же контрактами, которые позже будут использовать реальные адаптеры.
