# GreenCore

GreenCore — платформа цифровых двойников и поддержки решений для физических объектов.

Первая вертикаль — умная теплица: публичная realtime-симуляция, которая наглядно сравнивает ручное и автоматическое управление по микроклимату, ресурсам, урожайности и прибыли.

## Цель текущего MVP

Создать публичную демонстрацию, в которой сторонний наблюдатель видит, как автоматизация в реальном времени:

- удерживает температуру и влажность почвы в допустимых пределах;
- предотвращает стресс растения и необратимую потерю урожая;
- расходует воду и электроэнергию;
- влияет на прогноз выручки и прибыли;
- объясняет каждое значимое решение системы.

## Архитектура

Монорепозиторий:

```text
apps/
  demo/                 # React-интерфейс публичной симуляции
packages/
  domain-model/         # общие типы объектов, устройств и телеметрии
  simulation-core/      # детерминированный движок цифрового двойника
  shared/               # общие утилиты
docs/
  architecture/         # архитектурные решения
  simulation/           # описание модели симуляции
```
